# 📊 Frequentist Inference Case Study – Insurance Dataset

This project is a statistical analysis case study focused on **Frequentist Inference** using real-world insurance data. The goal is to estimate population parameters, test hypotheses, and draw conclusions from a random sample using foundational statistical methods.

---

## 🔍 Overview

The analysis investigates whether a sample of 1300 insurance customers (from a larger dataset of 1338) is statistically representative of the full population. The work is split into two major notebooks:

### 🧪 Part A – Exploratory Analysis
- Load and clean data
- Visualize distributions of charges, BMI, and regions
- Generate descriptive statistics
- Validate if the sample mimics the population

### 🧪 Part B – Hypothesis Testing
- One-sample t-tests for mean charges
- Proportion tests (e.g., smokers vs. non-smokers)
- Confidence intervals and margin of error
- Interpretation of p-values and confidence levels
